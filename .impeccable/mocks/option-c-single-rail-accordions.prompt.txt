Use case: ui-mockup
Asset type: high-fidelity product design comparison comp for Eidon settings, Option C
Primary request: Render a production-grade flat UI mockup of Eidon’s single-rail Settings experience using local tabs and inline accordions. This is a direct orthographic interface composition, not a photograph, not a device floating in a scene, and not a marketing page.
Scene/backdrop: 16:9 landscape design comp on Eidon’s near-black app background.
Structure: A large desktop application viewport occupying roughly 78% of the canvas, with one smaller portrait mobile viewport aligned at the right. The desktop has exactly two functional regions: a 248px global Settings rail and one broad Skills content page. There is no contextual second sidebar and no permanent record-detail pane.
Desktop global Settings rail text: “Settings”, “PERSONAL”, “Account”, “ASSISTANT”, “General”, “Providers”, “Personas”, “Memories”, “CAPABILITIES”, “MCP Servers”, “Skills”, “AUTOMATION”, “Scheduled automations”, “ADMINISTRATION”, “Users”. Make “Skills” selected with a restrained soft violet selection.
Main content: breadcrumb “Settings / Skills”; title “Skills”; subtitle “Create and manage reusable instructions for Eidon.”; button “Add skill”; search “Search skills”; tabs “All skills”, “Built-in”, and “Custom”. Show a vertical list where “Research Assistant” is selected and expanded inline with a CUSTOM badge and Enabled state. Inside it, show accordion sections “Details” expanded, “Instructions” collapsed with “Research and source evaluation guidance”, and “Availability” collapsed with “Enabled”. Show fields “Name” and “Description”, plus “Unsaved changes”, “Save changes”, and “Discard”. Below it show collapsed rows “Web Search”, “Image Analysis”, and “Code Reviewer”.
Mobile inset: back label “Settings”, title “Skills”, search, tabs, Research Assistant expanded inline with the three accordion rows, and sticky full-width “Save changes”.
Style: same Eidon Private Control Room system as Option A. Inter-like compact typography; near-black #0a0a0a; sidebar #0f0f0f; panel zinc #18181b; text #f4f4f5; muted #71717a; faint hairlines; scarce violet #8b5cf6; 12px corners; flat tonal depth; no card nesting.
Constraints: no contextual second sidebar, no permanent detail pane, coherent hierarchy, accessible contrast, desktop controls 36–40px high, mobile controls 44–48px high. Render quoted labels legibly.
Avoid: perspective, glossy device mockups, gradients, neon fog, purple washes, huge headings, bento dashboards, excessive pills, tiny controls, nested cards, illegible microtext, watermarks, and Mobbin branding.
